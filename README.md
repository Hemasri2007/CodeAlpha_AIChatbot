## Project Description : 

The AI Chatbot is a simple Java-based console application that simulates a basic conversation between a user and a chatbot. The chatbot responds to predefined user inputs such as greetings, questions about Java, internships, and general interactions. It demonstrates the use of conditional statements, loops, and string handling in Java to create an interactive command-line chatbot experience.

## Objectives :

- To develop a basic conversational chatbot using Java.
- To understand user input handling with the Scanner class.
- To implement decision-making using conditional statements.
- To practice string manipulation and pattern matching.
- To create an interactive console-based application.
## Tools and Technologies Used :

  - Programming Language: Java
  - IDE: VS Code
    
## Concepts Used :

   - Scanner Class
   - Loops (while loop)
   - Conditional Statements (if-else)
   - String Handling
   - User Input Processing
- Platform: Console-Based Application

## Features :

- Responds to greetings such as "Hello" and "Hi"
- Answers basic conversational questions
- Provides information about Java programming
- Shares information about internships
- Responds to thank-you messages
- Supports continuous conversation until the user exits
- Ends the chat when the user types "bye"
## How It Works :

- The chatbot welcomes the user.
- The user enters a message through the console.
- The input is converted to lowercase for easy comparison.
- The chatbot checks the message against predefined keywords.
- Based on the detected keyword, it generates an appropriate response.
- If no matching keyword is found, it displays a default response.
- The conversation continues until the user enters "bye".
- The chatbot displays a goodbye message and terminates.
## Keywords Supported :

    --User Input--      ||  --Bot Response--
    -Hello / Hi         ||  -Greeting message
    -How are you        ||  -Status response
    -What is your name  ||  -Chatbot introduction
    -Tell me about Java ||  -Information about Java
    -Internship         ||   -Internship information
    -Thank you          ||    -Welcome response
    -Bye                ||    -Ends the chat
